PALM OF ASH — WEBSITE STARTER

Open index.html in your browser to preview the site.

TO PUBLISH FOR FREE:
1. Create a GitHub account and a new public repository named palm-of-ash.
2. Upload index.html, style.css, script.js, and the assets folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, main, / (root), then Save.
4. Your site will be at https://YOUR-USERNAME.github.io/palm-of-ash/ once deployed.

BEFORE PUBLISHING:
- Replace the placeholder email in index.html and remove the setup-needed behavior in script.js.
- Add actual streaming, video, and merchandise links when available.
- Review and approve the short artist bio and track descriptions.
- Confirm which images you want public.

This is a static website. It has no checkout, mailing-list backend, or built-in music hosting yet. It uses Google Fonts if online; otherwise system fonts display.
